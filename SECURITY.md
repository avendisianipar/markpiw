## Melaporkan kerentanan

Jangan membuka issue publik, discussion, atau pull request yang berisi detail kerentanan.

Saat ini private vulnerability reporting GitHub belum diaktifkan. Hubungi
[maintainer melalui profil GitHub](https://github.com/avendisianipar) tanpa menyertakan detail
sensitif untuk meminta kanal pelaporan privat. Setelah kanal privat tersedia, sertakan:

- versi dan host yang terdampak (VS Code atau web);
- langkah reproduksi atau proof of concept minimum;
- dampak yang mungkin terjadi;
- mitigasi sementara, jika diketahui.

Maintainer akan mengonfirmasi penerimaan laporan dan mengoordinasikan publikasi setelah
perbaikan tersedia. Jangan mengungkapkan kerentanan sebelum ada kesepakatan waktu publikasi.

Masalah umum yang tidak memiliki dampak keamanan tetap dilaporkan melalui
[issue tracker](https://github.com/avendisianipar/markpiw/issues/new/choose).
