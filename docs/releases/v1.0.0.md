# Release 1.0.0

Rilis stabil pertama markpiw—editor Markdown WYSIWYG lokal untuk VS Code yang menjaga file
`.md` tetap mudah dibaca dan di-review di Git.

## Sorotan

- **Editing visual yang lebih lengkap:** toolbar dan slash menu kini memakai item, ikon,
  label, dan pengelompokan yang konsisten.
- **Blok Markdown kaya:** tabel lengkap, callout, rumus dengan KaTeX, diagram Mermaid, dan
  syntax highlighting untuk code block.
- **Navigasi dan tampilan:** outline dokumen melayang serta tema terang/gelap di web app dan
  VS Code.
- **Source preservation:** hanya blok yang diedit yang diserialisasi ulang sehingga Git diff
  tetap terarah.
- **Lokal dan privat:** tidak ada server markpiw, analytics, atau telemetri.
- **Fail-safe:** bila perubahan tidak dapat disimpan tanpa mengubah makna dokumen, editor
  menjadi baca-saja dan tidak menulis file.
- **Fondasi open source:** lisensi MIT, notice lisensi otomatis, CI, issue forms, panduan
  kontribusi, Code of Conduct, dan kebijakan keamanan.

## Instalasi

1. Unduh `markpiw.vsix` pada bagian **Assets** di bawah.
2. Di VS Code, buka panel **Extensions**.
3. Klik **`…`** → **Install from VSIX…** lalu pilih file tersebut.
4. Klik kanan file `.md` → **Buka dengan markpiw**.

Membutuhkan VS Code 1.95 atau lebih baru.

## Penting untuk pengguna 0.1.0

ID extension berubah dari `markpiw-internal.markpiw` menjadi `avendisianipar.markpiw`.
Uninstall extension lama terlebih dahulu, lalu pasang `markpiw.vsix` dari rilis ini. Setting
`markpiw.assetsFolder` tetap terbawa; pilihan tema mungkin perlu dipilih ulang sekali.

Lihat [README](https://github.com/avendisianipar/markpiw#readme) untuk panduan lengkap dan
[CHANGELOG](https://github.com/avendisianipar/markpiw/blob/main/CHANGELOG.md) untuk riwayat
perubahan.
