# Release 1.1.0

Tampilan dokumen di markpiw kini meniru render GitHub, sehingga README dan dokumen lain terlihat
sama seperti saat dibuka di github.com. File `.md` tidak berubah.

## Sorotan

- **Spacing seperti GitHub:** padding halaman 32px dan lebar konten maks. 1012px. Jarak
  kiri-kanan di VS Code jauh lebih rapat. Ukuran serta jarak heading, paragraf, list, kode, dan
  tabel mengikuti GitHub.
- **Callout seperti alert GitHub:** judul berikon, garis kiri berwarna, tanpa latar. Marker
  `[!NOTE]` disembunyikan dan baru muncul saat kursor berada di barisnya.
- **HTML blok ala GitHub:** `<div align="center">` dan `<p align="…">` meratakan isinya tanpa
  menampilkan tag mentah. `<details>`/`<summary>` tampil terlipat dan bisa dibuka/ditutup.
  Source tag muncul saat kursor masuk ke wilayahnya.
- **Tabel:** selebar isinya dengan baris belang; header kosong (`| | |`) tampil tipis.
- **Diagram dan rumus:** Mermaid dan blok `$$` hanya menampilkan hasil render; klik untuk
  mengedit source.

## Instalasi

1. Unduh `markpiw.vsix` pada bagian **Assets** di bawah.
2. Di VS Code, buka panel **Extensions**.
3. Klik **`…`** → **Install from VSIX…** lalu pilih file tersebut.
4. Jalankan **Developer: Reload Window**, lalu klik kanan file `.md` → **Buka dengan markpiw**.

Membutuhkan VS Code 1.95 atau lebih baru. Extension yang dipasang dari `.vsix` tidak
diperbarui otomatis; pasang file rilis ini di atas versi sebelumnya.

Lihat [CHANGELOG](https://github.com/avendisianipar/markpiw/blob/main/CHANGELOG.md) untuk
riwayat perubahan lengkap.
