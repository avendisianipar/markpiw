# Release 1.2.0

markpiw kini bisa mencari teks di dokumen, dan blok HTML sederhana di README tampil seperti di
GitHub. File `.md` tidak berubah.

## Sorotan

- **Cari di dokumen (Ctrl/⌘+F):** tekan Ctrl/⌘+F atau tombol cari di toolbar. Semua hasil
  disorot dengan hitungan "x dari y". Enter / Shift+Enter berpindah ke hasil berikutnya /
  sebelumnya, Esc menutup kotak cari dan menaruh kursor di hasil terakhir. Hasil di isi
  `<details>` yang tertutup atau di source diagram/rumus ikut ditampilkan. Di VS Code, find
  widget bawaan tidak ikut muncul.
- **Blok HTML seperti GitHub:** blok seperti `<p align="center"><em>…</em></p>` atau
  `<h1 align="center">Judul</h1>` tampil ter-render, bukan sebagai kotak "Markdown mentah".
  Klik hasil render untuk mengedit source-nya. Hanya teks dan tag inline yang aman yang
  dirender; blok HTML lain tetap tampil mentah.

## Instalasi

1. Unduh `markpiw.vsix` pada bagian **Assets** di bawah.
2. Di VS Code, buka panel **Extensions**.
3. Klik **`…`** → **Install from VSIX…** lalu pilih file tersebut.
4. Jalankan **Developer: Reload Window**, lalu klik kanan file `.md` → **Buka dengan markpiw**.

Membutuhkan VS Code 1.95 atau lebih baru. Extension yang dipasang dari `.vsix` tidak
diperbarui otomatis; pasang file rilis ini di atas versi sebelumnya.

Lihat [CHANGELOG](https://github.com/avendisianipar/markpiw/blob/main/CHANGELOG.md) untuk
riwayat perubahan lengkap.
