# Release 1.3.0

markpiw kini bisa menelusuri dokumen spec: `requirements.md`, `design.md`, dan `tasks.md` di
folder yang sama saling terhubung, seperti fitur spec di Kiro. File `.md` tidak berubah.

## Sorotan

- **Bar langkah spec:** buka salah satu dari `requirements.md`, `design.md`, atau `tasks.md`.
  Di bawah toolbar muncul **Requirements › Design › Task list** untuk berpindah file, progres
  task (dari baris `Status: [ ]/[~]/[x]` atau checkbox), dan jumlah requirement yang sudah
  ditangani task.
- **ID yang bisa diklik:** heading yang diawali ID, seperti `### FR-1: …` atau `### T3 — …`,
  menjadi definisi. Setiap sebutan ID itu di file spec mana pun tampil sebagai chip. Arahkan
  kursor ke chip untuk melihat ringkasannya, lalu Ctrl/⌘+klik untuk lompat ke definisinya.
- **Panel Trace:** menampilkan keterkaitan bagian yang sedang Anda baca: bagian yang
  dirujuknya, bagian yang merujuknya, dan bagian di dokumen lain yang menyebut istilah kode
  yang sama (endpoint, nama tabel, kode error). Tab **Cakupan** menampilkan requirement yang
  belum dirujuk task mana pun.
- **Link ke heading:** link seperti `design.md#api-endpoints` atau `#bagian-lain` kini membuka
  file dan menggulir ke heading tujuannya.

## Cara menautkan task ke requirement

Tambahkan baris yang menyebut ID requirement di bawah heading task, misalnya:

```markdown
### T1 — Schema database
**Requirements:** FR-1, FR-5
```

Sebutan ID di mana pun di file spec dihitung sebagai tautan.

## Instalasi

1. Unduh `markpiw.vsix` pada bagian **Assets** di bawah.
2. Di VS Code, buka panel **Extensions**.
3. Klik **`…`** → **Install from VSIX…** lalu pilih file tersebut.
4. Jalankan **Developer: Reload Window**, lalu klik kanan file `.md` → **Buka dengan markpiw**.

Membutuhkan VS Code 1.95 atau lebih baru. Extension yang dipasang dari `.vsix` tidak
diperbarui otomatis; pasang file rilis ini di atas versi sebelumnya.

Lihat [CHANGELOG](https://github.com/avendisianipar/markpiw/blob/main/CHANGELOG.md) untuk
riwayat perubahan lengkap.
